# Drawnix 个人工作台：功能与发布状态

本文件介绍基于 [Drawnix](https://github.com/plait-board/drawnix) 制作的个人工作台及已验证的改动。**本分支目前只提供说明；个人工作台的源码和部署文件尚未在此分支发布。** 下文列出的服务器功能不能直接通过安装本分支获得。

## 定制功能

- 以 Django 和 PostgreSQL 提供个人文件存储；提供文件夹、收藏、回收站和版本历史。
- 对已保存版本创建只读分享快照，可设置有效期或撤销；持有链接的人可查看快照。
- 提供普通个人账户登录和密码修改；按配置可要求首次登录修改临时密码。
- 编辑器增加文字左对齐、居中和右对齐，改进字号控件；支持多选及撤销重做。
- 增加思维导图概要、编号和节点间箭头相关功能，并保留上游编辑器能力。
- 修复某些英文字符组合触发意外换行和裁切，以及画布滚动后选框错位的问题。可编辑文件默认使用选择工具。

## 使用与安装

目前可按仓库自身的 README 安装和使用上游编辑器；本说明列出的服务器存储、账户及定制功能需要尚未发布的个人工作台源码，不能仅凭本分支完成部署。发布相关源码后，应按其提供的部署文档配置 PostgreSQL、反向代理、HTTPS、独立密钥和账户，并根据自己的环境验证备份与恢复。

在包含定制源码的开发环境中，前端常用命令为 `npm ci`、`npm run test:editor`、`npm run test:workspace`、`npm run typecheck` 和 `npm run build:web`。这些命令属于个人工作台源码，当前说明分支保留上游项目命令，以仓库 `package.json` 为准。

## 验证范围与限制

2026 年 10 月 30 日对当时本地定制源码重新运行：编辑器测试 227 项、工作台测试 23 项通过。此前使用独立浏览器样例验证文字输入、对齐、撤销、选框、保存和重载。服务器持久化及认证有此前的 PostgreSQL 和 HTTPS 验证记录。

这些结果针对本地定制版本，不是本说明分支的 CI 结果，也不代表所有环境均已验证。真实 Windows 中文输入法、不同浏览器、部署配置和恢复流程仍需各自环境验收；源码尚未发布前，其他人不能复现个人工作台的全部功能。
